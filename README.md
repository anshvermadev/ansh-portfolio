# Ansh Verma - Personal Portfolio

Welcome to the repository of my personal portfolio website. This project showcases my skills, experience, and projects as a Full Stack Developer. It is built with a focus on modern design, immersive 3D graphics, smooth animations, and high performance.

## 🌐 Live Website

Check out the live portfolio here: **[ansh-verma.xyz](https://www.ansh-verma.xyz)**

## ✨ Features

- **Modern Tech Stack**: Built using Next.js (App Router), React, and TypeScript for robust architecture and server-side rendering capabilities.
- **Immersive 3D & Animations**: Utilizes Three.js, React Three Fiber, Framer Motion, and GSAP for stunning visual effects, interactive elements, and smooth page transitions.
- **Smooth Scrolling**: Integrated Locomotive Scroll for a seamless, momentum-based scrolling experience.
- **AI Integration**: Features AI integration powered by Google Generative AI (Gemini) via the Vercel AI SDK.
- **State Management**: Uses Zustand for lightweight, fast, and scalable state management.
- **Contact Form**: Fully functional contact form powered by EmailJS, validated using Zod and React Hook Form.
- **SEO & Performance**: Highly optimized with Next.js metadata, JSON-LD for rich snippets, and monitored using Vercel Analytics and Speed Insights.

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites

Make sure you have Node.js and npm (or yarn/pnpm/bun) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/anshvermadev/ansh-portfolio.git
   cd ansh-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables:**
   Create a `.env.local` file in the root directory and add the following variables (refer to `.env.example`):
   ```env
   GOOGLE_API_KEY=your_google_api_key
   NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_emailjs_service_id
   NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_emailjs_template_id
   NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_emailjs_public_key
   NEXT_PUBLIC_EMAILJS_TO_EMAIL=your_email
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Open the app:**
   Open [http://localhost:3000](http://localhost:3000) in your browser to see the application running.
